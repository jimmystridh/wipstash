# Sustained genuine-native-agent benchmark

Frozen specification, independent semantic oracle, and exact local campaign tooling. This checkpoint preserves setup while the experiment runs; it is not a result or a performance claim. Four native coding agents author the features; the Python coordinator integrates only and does not implement features or resolve conflicts.

This Linux-only experimental harness currently uses explicit /workspace/shared cloud paths, requires a separately built core executable, and is not part of normal CI. Adapt fixture paths explicitly before reproducing elsewhere. The observer measures source projection, not webhooks or ChatGPT actions. No credentials, grants, live applications, generated state, private WIP, or raw agent conversations are included. Oracle inputs/reference were frozen before native author work; see independent_oracle/FROZEN.json.
